# RUN/ME

Личный трекер тренировок и самочувствия. Один самостоятельный файл `index.html` — никакой сборки и сервера не нужно, всё (стили, логика, данные) хранится прямо в браузере того, кто открывает страницу.

## Как выложить на GitHub и получить ссылку

1. **Создайте репозиторий**
   На github.com нажмите **New repository**, дайте имя (например `run-me`), сделайте его **Public**, нажмите **Create repository**.

2. **Загрузите файл**
   На странице репозитория нажмите **Add file → Upload files**, перетащите `index.html` из этого набора, внизу нажмите **Commit changes**.

3. **Включите GitHub Pages**
   Зайдите в **Settings → Pages** (в левом меню).
   В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
   В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.

4. **Получите ссылку**
   Через минуту-две на той же странице появится адрес вида:
   `https://ваш-логин.github.io/run-me/`
   Это и есть ссылка, которой можно делиться.

## Обновление

Когда захотите что-то изменить в приложении — просто загрузите новую версию `index.html` тем же способом (шаг 2), GitHub Pages обновит сайт автоматически за пару минут.

## Важно про данные

Данные (сон, пульс, самочувствие и т.д.) сохраняются **в браузере конкретного устройства**, а не на сервере и не в самом GitHub. Это значит:
- на телефоне и на компьютере будут разные, несвязанные данные;
- если очистить данные сайта в браузере — история удалится;
- при желании синхронизировать данные между устройствами или хранить их надёжнее, понадобится добавить облачное хранилище — дайте знать, если такое пригодится.
